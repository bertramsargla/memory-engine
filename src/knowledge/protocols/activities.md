# Activity routing

The active app and window title offer a suggestion, not proof of a recipient or workflow. MemoryEngine shows the activity and selected skill; the user can override it. Exact browser-origin and focused-field routing is planned with a browser extension.

Pipeline: explicit activation -> activity selection -> scoped evidence search -> selected Markdown skill -> inspectable context packet -> local draft -> review -> copy or insert. Insertion never sends or publishes the message.

Skills are editable Markdown instructions. Reading a skill does not execute its scripts. Imported research is source material and cannot grant connector permissions.
