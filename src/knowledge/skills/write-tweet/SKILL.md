---
name: write-tweet
description: Draft an original X or Twitter post using the user's selected topic and relevant MemoryEngine evidence. Use for a new post, not a private message or email reply.
---

Use the user's thesis and language. Lead with a concrete observation; omit generic openings, invented metrics, hashtags and emoji unless requested. Aim for a single short post by default. Do not silently turn a request into a thread.

Treat captured claims and agent conversations as attributed source material. A mention of a company or person does not prove employment, a partnership or an endorsement. If the requested factual claim lacks evidence, identify the missing support.

Use retrieved writing preferences only when relevant. Keep internal citations in the evidence panel; include a public source link in the draft only when the user requests one or it belongs naturally in the post. Draft creation does not authorize publication.
